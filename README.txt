Elaine Lustig Cohen responsive one-page website

Files:
- index.html
- style.css
- assets/ (the images supplied in the uploaded ZIP, plus the Canva SVG reference exports)

To use:
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open index.html with Live Server or a browser.
4. Keep the assets folder beside index.html so image paths work.

The navigation uses position: sticky and anchors to sections. CSS Grid uses 12-column layouts on larger screens and stacks sections on narrow phones. The geometric circle/star shapes use aspect-ratio and clamp() sizing.
